### ♡ **How to run?**

* Ensure you have [Elle](https://github.com/acquitelol/elle) and [nodemon](https://www.npmjs.com/package/nodemon) installed

```console
$ git clone https://github.com/acquitelol/ellecord
```

```console
$ cd ellecord && nodemon
```
